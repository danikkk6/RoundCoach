# RoundCoach — ИИ-тренер по CS2

Учебный проект: вводишь карту, сторону и экономику, получаешь закупку, распределение игроков и план раунда. Интерфейс на русском, адаптируется к телефону.

## Запуск в VS Code

1. Установи Node.js версии 20.12 или новее (https://nodejs.org).
2. Открой папку RoundCoach в VS Code: File → Open Folder.
3. Открой Terminal → New Terminal и введи:

```powershell
node server.js
```

4. Открой http://localhost:3000 в браузере. Сервер работает, пока открыт терминал. Остановить: Ctrl+C.

Устанавливать пакеты не требуется. Не запускай через Live Server: страница использует собственный сервер. Если порт занят, создай .env с PORT=3001 и открой http://localhost:3001.

## Подключение настоящего ИИ

1. Создай аккаунт https://huggingface.co.
2. В https://huggingface.co/settings/tokens создай токен с разрешением Inference Providers.
3. Скопируй .env.example в файл .env рядом с server.js.
4. В .env укажи HF_TOKEN=твой_токен. Не вставляй токен в script.js и не публикуй .env.
5. HF_MODEL по умолчанию openai/gpt-oss-120b. Если модель недоступна, выбери доступную через https://huggingface.co/playground и укажи её ID в HF_MODEL.
6. Перезапусти сервер и выбери «ИИ · Hugging Face» в форме.

Запросы к провайдерам могут расходовать кредиты аккаунта. Доступность моделей и тарифы зависят от Hugging Face: https://huggingface.co/docs/inference-providers/pricing.

Без токена работает только локальный демонстрационный режим: это правила, а не языковая модель. При ошибке ИИ показывается локальный план и явное сообщение. Реальный запрос к модели нужно проверить со своим токеном.

## Файлы

- index.html — форма и структура страницы.
- style.css — оформление.
- script.js — отправка формы, вывод результата, примеры, копирование.
- coach.js — валидация, расчёт закупки и учебные тактики для семи карт.
- server.js — локальный сервер и обращение к Hugging Face; ключ остаётся на сервере.
- coach.test.js — проверка бюджета и входных данных.

## Как это работает

Сервер проверяет данные, выбирает базовый тип закупки, считает предметы в пределах личного бюджета и составляет план по карте. В режиме ИИ передаёт ситуацию и этот расчёт модели: она объясняет решение и предлагает дополнительный разбор. Это помощник по запросу пользователя, без доступа к игре и автоматического управления.

Тактики — учебные эвристики для 5 игроков, не гарантия победы. Средние деньги команды не заменяют бюджет каждого игрока. Броня в форме предполагается полной; сохранённые гранаты, дропы и деньги остальных игроков не моделируются. Планы не содержат проверенных lineup-бросков. Раунды 1 и 13 считаются пистолетными для обычного MR12; для овертайма отдельные правила не добавлены. Серия поражений — упрощённый ориентир выплаты, не точная симуляция экономики после побед. Цены оружия хранятся в coach.js и могут требовать обновления после патчей.
