# RoundCoach — ИИ-тренер по CS2

Укажи карту, сторону, деньги и снаряжение: ИИ выбирает закупку, роли пяти игроков и план раунда. Интерфейс на русском. Локального движка тактик и режима демо больше нет: без API-ключа или при ошибке провайдера приложение показывает ошибку, а не заранее заданный совет.

## Запуск и бесплатный API

Требуется Node.js 20.12 или новее. Зависимостей для установки нет.

1. Создай аккаунт [Groq](https://console.groq.com) на Free Plan и ключ в [API Keys](https://console.groq.com/keys).
2. Скопируй `.env.example` в `.env` рядом с `server.js`.
3. Укажи `GROQ_API_KEY=твой_ключ`. Не добавляй ключ в браузерный код или GitHub.
4. Запусти `node server.js` и открой http://localhost:3000.

По умолчанию используется `GROQ_MODEL=openai/gpt-oss-120b`. При необходимости выбери другую модель Groq с поддержкой JSON Object Mode. Для другого порта задай `PORT=3001` и перезапусти сервер. Live Server не подходит.

Groq предоставляет Free Plan с ограничениями, а не безлимитный бесплатный API. Текущие лимиты смотри в [официальной документации](https://console.groq.com/docs/rate-limits) и своём аккаунте. Для бесплатного использования оставайся на Free Plan. Приложение не переключается на платных провайдеров. Некорректный ответ может вызвать ещё один запрос исправления, который также расходует квоту.

Реальный запрос требует твоего ключа. Автоматические тесты используют подставные ответы, не расходуют квоту и не доказывают качество тактики модели.

## Как ИИ выбирает план

`ai-coach.js` отправляет провайдеру ситуацию, словарь карты и подходящие выдержки из `pro-references.json`. Системная инструкция просит сравнивать варианты закупки с учётом экономики, сохранённого оружия и следующего раунда; давать конкретные позиции, размены, владельцев гранат, условия смены плана, запасной вариант и короткий голосовой колл.

ИИ создаёт всю закупку и тактику. Сервер проверяет структуру ответа, пять ролей, диапазоны цен, сумму в пределах личного бюджета и допустимые ссылки; итоговую сумму и остаток считает сам. Предметы выбираются по ID из словаря `equipment.js`: в закупке максимум четыре гранаты, максимум две флешки, остальные типы по одной. Molotov доступен T, Incendiary и kit — CT. Каждый элемент — один предмет; наборы и количества не принимаются. Эти проверки не выбирают стратегию. Некорректный ответ запрашивается повторно один раз. Общий таймаут — 45 секунд. Ошибки ключа, квоты и сети видны пользователю.

«Решающий раунд» отмечается автоматически для 12, 24, 30, 36 и далее через шесть раундов. Ручного переключателя нет, сервер вычисляет отметку сам. Это конец половины или блока овертайма, а не подтверждённый матч-пойнт: выбор закупки остаётся за ИИ. Диапазон формы — 1–120; используется MR12 и блоки MR3 в овертайме. Размер стартовых денег овертайма нужно уточнить в комментарии.

Цены предметов — оценки модели, а не проверенные данные актуального патча. Сервер проверяет арифметику, но не гарантирует правильность цен, доступность оружия или выполнимость гранат. Перед закупкой сверяйся с игрой. Полная броня предполагается сохранённой; точные деньги и инвентарь остальных игроков, спавны и сохранённые гранаты неизвестны. Средние деньги команды не гарантируют дроп. Раунды после 24 требуют уточнений по овертайму.

## Реальный про-геймплей и источники

Одной инструкции «играй как профессионал» недостаточно, чтобы модель изучила матчи. Поэтому ответы могут опираться на небольшой редактируемый набор выдержек с источниками. Сейчас он содержит руководство Refrag по CS2 defaults и два исторических разбора про-игроков от аналитика innersh1ne / SCOPE.GG. Это начальная база принципов, а не полноценный корпус актуальных CS2 матчей.

Исторические CS:GO примеры явно обозначены: их нельзя выдавать за текущую мету CS2 или переносить точные броски без проверки. Для карт и сторон без подходящих источников модель должна честно указывать, что даёт общий совет. Сервер разрешает ссылки только на переданные записи; соответствие текстовых утверждений источнику требует проверки человеком.

Чтобы расширить базу, добавляй в `pro-references.json` проверенные краткие разборы CS2 матчей:

- Уникальный `id`, название `title`, проверенный HTTPS-адрес `url`.
- `maps` из списка карт формы и `side`: `T`, `CT` или `any`.
- `kind`: игра, дата матча, команды, номер раунда или таймкод источника; для руководства укажи, что это не матч.
- `summary`: наблюдаемое решение, доступные ресурсы, результат, ограничения и применимый принцип своими словами.

Сервер выбирает записи по карте и стороне; они доступны модели как контекст, а выбранные моделью источники отображаются в плане и копируются вместе с ним. Это контекстное дополнение, не обучение весов модели. Приложение не скачивает и не анализирует `.dem` или видео и не заявляет, что наблюдало матчи. После изменения базы перезапусти сервер. Набор должен оставаться небольшим, чтобы укладываться в бесплатную квоту.

## Публикация на Render

Создай Web Service, подключи репозиторий и ветку с изменениями. Runtime: Node; Build Command: `npm install`; Start Command: `node server.js`. В Environment добавь `HOST=0.0.0.0`, `NODE_VERSION=24`, `GROQ_API_KEY` и `GROQ_MODEL=openai/gpt-oss-120b`. `PORT` задаётся хостингом.

GitHub Pages не запускает Node.js-сервер. Ключ хранится на сервере. Публичная демонстрация не имеет авторизации и ограничения запросов по пользователю: посетители разделяют квоту Groq. Для широкого доступа добавь авторизацию и ограничение запросов.

## Файлы и проверка

- `index.html`, `style.css`, `script.js` — форма и отображение плана.
- `coach.js`, `match-rules.js` — проверка входных данных, контекст раунда и названия позиций карт.
- `equipment.js` — словарь предметов, ограничения стороны и количества гранат; тактики не содержит.
- `ai-coach.js` — инструкция, запрос Groq, проверка ответа и исправление некорректного ответа.
- `pro-references.json` — проверенные выдержки с источниками.
- `server.js` — HTTP-сервер; API-ключ остаётся на сервере.
- `coach.test.js`, `ai-coach.test.js`, `server.test.js`, `match-rules.test.js` — проверка данных, лимитов гранат, контекста раунда, взаимодействия с провайдером и API.

Запусти `node --test`. Для ручной проверки задай ключ, перезапусти сервер и попробуй «Эко на CT», «Выход на T» и «Низкий бюджет». Проверь отметку на раундах 12, 24, 30, 36 и её исчезновение на 13, 25, 31. Проверь изменение решений, доступность закупки, источники и допущения. Без ключа ожидается понятная ошибка, без локального плана.
